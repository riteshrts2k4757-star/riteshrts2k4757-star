## 🚀 Featured Projects

### 🌾 FarmTrace — IoT-Based Farm-to-Fork Traceability

An IoT traceability solution designed to monitor environmental conditions during agricultural transportation and improve supply-chain data integrity.

- **Hardware:** ESP32, environmental sensors, GPS, MicroSD, RTC, and communication modules.
- **Communication:** MQTT and cellular connectivity concepts, including the SIM A7670C 4G LTE module.
- **Features:** Temperature, humidity and gas monitoring, offline telemetry storage, automatic data synchronization, and tamper detection.
- **Integrity:** SHA-256 verification and blockchain-based traceability concepts.

**Focus:** Embedded systems · IoT · MQTT · Data integrity · Supply-chain monitoring

### 📡 Offline SD-WAN — ESP32 & ESP8266 Wireless Network

An offline wireless communication system designed to transfer data between a central ESP32 hub and ESP8266 branch nodes using NRF24L01 radio modules.

- HTTP REST endpoints for sending and receiving data
- NRF24L01-based wireless communication
- Packet numbering, acknowledgements, retries, and CRC checks
- Message fragmentation and reassembly
- Telemetry, device status, and communication statistics

**Focus:** ESP32 · ESP8266 · NRF24L01 · C++ · REST APIs · Wireless networking

### 🌍 Tour & Travel Booking Platform
